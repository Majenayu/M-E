# Contributing to M-E

This repository is a prototype. Keep changes focused on the documented project scope and preserve existing behavior unless a change is explicitly proposed.

## Workflow

1. Create a focused branch from the default branch.
2. Install dependencies with `npm install` (and, for `Navigation-Project`, separately in `nav-backend/`).
3. Copy `.env.example` to `.env` and use local, non-production values.
4. Run the validation commands documented in `README.md` and `package.json`.
5. Update the README, API notes, or changelog when behavior or setup changes.

Do not commit credentials, uploaded files, generated output, or personal data.
